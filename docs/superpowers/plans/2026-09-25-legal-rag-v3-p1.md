# P1 Ingestion + Retrieval Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** JSONL corpus ingestion with legal-aware chunking, and a hybrid retrieval pipeline exposed at `/api/retrieval/search` that satisfies the `production_rules/` contract.

**Architecture:** Admin uploads JSONL → object storage → arq job → contract validation → chunker → embedder (TEI) → Postgres (pgvector + pg_search). Retrieval = filtered vector + BM25 in SQL → RRF → TEI rerank → bounded authority → noise cut, with exact-reference pinning in `full` mode.

**Tech Stack:** FastAPI, SQLAlchemy async, Alembic, ParadeDB (pg_search, pgvector), TEI, arq, boto3.

**Spec:** `docs/BRIEF.md` (the coding brief; sections 5, 6, 8, 9.1, 14) + `CONTEXT.md`. The previous P1 spec/plan (v2-port, PDF/DOCX) is superseded and parked on branch `p1-draft-v2port`.

## Global Constraints

- Every embedding goes through `app/retrieval/embedder.py` (`build_passage_input`, `build_query_input`, `embed_texts`). No other TEI `/embed` caller.
- Filters (ACL `collection_id`, `embedding_model = current`, validity window, `status <> 'repealed'`) live **inside** the SQL of vector and BM25 queries.
- One chunk = one citation. Never merge two articles. `chunk_kind ∈ {article, clause_split, semantic, table}`.
- Context header: `{doc_type_ar}: {title_ar} — {path joined " — "} — {article_label}`.
- `final = p × (0.85 + 0.15 × authority)`, `p = sigmoid(logit)`. Never raw logits downstream.
- Constants: VECTOR_K=50, BM25_K=50, FUSED_K=30, RRF K=60, w=1.0/1.0, MIN_RERANK_PROB=0.15, PER_CLAIM_K=6, MAX_CHUNK_TOKENS=450, reranker truncation 512.
- `production_rules/` copied unchanged. Rule 3 contract: `POST /api/retrieval/search` body `{query, as_of_date, collections, mode, top_k, include_repealed}`, response `{results: [{chunk_id, unit_id, collection_id, status, score}], latency_ms}`; `collection_id` is an **integer**.
- User-facing strings Arabic; code English.
- Tests: unit tests on SQLite (fast, CI); integration tests (`-m integration`) against real ParadeDB with a fake embedder/reranker (CI service container + local `v3_postgres`).

## Review Focus

1. ACL leak: a user with collections {1} querying with `collections=null` or `collections=[2]` must never see collection 2 rows (all modes, incl. pinned exact refs).
2. Repealed leak: repealed chunks never returned unless `include_repealed=true` (incl. pinned exact refs).
3. Re-ingesting the same `doc_id` replaces its units/chunks (no duplicates, no orphans).
4. Eastern-digit citations (`المادة ٤١ من القانون رقم ٦ لسنة ٢٠١٠`) pin the same unit as Western digits.
5. Reranker/TEI failure surfaces as a clean Arabic 503, never a silent empty result.
