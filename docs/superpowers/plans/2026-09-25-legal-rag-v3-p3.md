# P3 Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans.

**Goal:** An Arabic RTL web app where a user logs in, submits an opinion, watches live progress, and reads the verified result; admins manage users, collections and corpus ingestion.

**Architecture:** React 18 + TypeScript + Vite SPA, Tailwind (brief §10.1 tokens), TanStack Query for server state, React Router. `fetch` wrapper with access/refresh tokens; SSE read through `fetch` streaming (EventSource cannot send the bearer header). Served by nginx, which also proxies `/api` to the API (SSE unbuffered).

**Spec:** `docs/BRIEF.md` §10 (pages 1–4 and 6; the editor page 5 is P4).

## Global Constraints
- `dir="rtl" lang="ar"`, IBM Plex Sans Arabic, all UI copy Arabic, Western digits for article numbers (D-008).
- Palette: primary `#1F4E79` (hover `#173C5E`), light blue `#E8F1FB`, accent `#3B82C4`, bg `#F5F7FA`, surface `#FFFFFF`, border `#D9DEE5`, muted `#5B6675`, text `#1E2733`; supports `#3B82C4/#E8F1FB`, contradicts `#B42318/#FDECEA`, insufficient `#5B6675/#EEF1F4`, needs-review `#B54708/#FEF3E2`. Radius 8px, no gradients.
- Keyboard navigable, visible focus rings, logical CSS properties.
- The UI renders the report from structured data; it never invents text.

## Tasks
1. Scaffold (Vite/TS/Tailwind/Query/Router), API client with refresh, SSE parser (+ vitest), auth context, layout.
2. Login page.
3. Reviews list (status badge, score, date, owner; status filter; "مراجعة جديدة").
4. New review (question, text or drag-and-drop file, as-of date, collections).
5. Review result: status badge + score, live stage stepper (SSE), action bar (export/approve/edit disabled until P4), tabs: الملخص · تحليل الادعاءات · المراجع (مؤيدة | معارضة, full-text drawer) · آراء مشابهة · الرأي المقترح.
6. Admin: users & roles + collection ACL, collections, ingestion jobs (upload JSONL, progress, per-row errors).
7. nginx image + compose service `v3_frontend` (:8300); CI job (typecheck, test, build). Push; CI green.
